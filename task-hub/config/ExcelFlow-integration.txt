Task Hub 0.7.1 — Connect and ExcelFlow

CONNECT
Only Gmail and IMAP / POP3 are currently available.
Microsoft 365 and Outlook Classic connections are temporarily unavailable.
Saved Microsoft routines are preserved but do not run. Edit them to select a
connected Gmail or IMAP / POP3 sender before saving and running them again.

Gmail: enable Read email attachments for ExcelFlow and reconnect to read raw
workbooks. The publisher needs Google's gmail.readonly scope configured.
IMAP / POP3: use your provider's incoming TLS server, username and password/app
password. IMAP defaults to port 993, POP3 to 995. SMTP is optional for reading,
but required for sending routines. SMTP requires TLS or STARTTLS and uses the
same password, with an optional different username. Ask IT which methods your
account supports; providers requiring OAuth may block password-based access.
Passwords are stored in Windows Credential Manager, not routine files.
Browsing never deletes mail or marks it read. POP3 header browsing needs TOP.
IMAP can save drafts; POP3 drafts are local .eml files. SMTP does not automatically
save a Sent Items copy.

EXCELFLOW
Open ExcelFlow in the sidebar. The sidebar collapses automatically; use the
button in the top bar to expand or collapse it again. Select DISC & FTG Reports.
The original ExcelFlow layout is retained with Task Hub's theme and fonts:
- Workbooks on the left; Report details on the right.
- Output location below, followed by actions and progress.
- Main menu, Manage IG names and Settings at the top right.
- Date preview, Run log and Issues under View run details.

Browse for a DISC workbook, an FTG workbook, or both. Alternatively choose
Read from email, select Gmail or IMAP / POP3, read folders and recent emails,
then assign the chosen workbook attachments as DISC or FTG. Choose Done to
return to the report screen. No separate ExcelFlow app folder is needed.

Use Both / DISC / FTG and Both / Normal / Special as in the original app.
Automatic period detection uses ALL_DISC_YYMM or ALL_FTG_YYMM filenames.
Files prefixed oriALL_ need a manual month/year in Settings or a renamed copy.
Settings includes decimals, the P160 multiplier, filename detection and date
recovery. Manage IG names changes Task Hub's own embedded engine settings.
Choose an output folder or keep Task Hub's output/ExcelFlow default.

Validate & preview checks dates without generating reports. Generate reports
creates a new report-run folder. Open results lets you choose a completed run,
select reports and add them to a new or existing email routine. Save that routine
to confirm its attachments. The reports are fixed copies; later report runs do
not automatically replace them. No email is sent by reading or generating files.

LEGACY REPORT RULES
New routines no longer expose Report Rules. Existing rules remain clearly marked
until explicitly removed. Add the intended attachments, remove legacy rules and save.

LIMITS
Raw workbooks: 100 MB each. Outgoing attachments: 10 files / 18 MB in total.
Only .xlsx/.xlsm workbook attachments are imported. Macros are not run.
Scheduled email requires Task Hub running in the tray, an awake computer and internet.
