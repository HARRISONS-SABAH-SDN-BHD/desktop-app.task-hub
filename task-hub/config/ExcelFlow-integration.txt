Harrison ExcelFlow + Task Hub

1. Generate DISC / FTG reports in Harrison ExcelFlow as usual.
2. In Task Hub, create or edit an email routine. Under Add files > ExcelFlow
   reports, click Choose ExcelFlow run.
3. Select the output folder containing run_summary.json and its Formatted...
   subfolders. Do not select the Desktop, a raw workbook or an inner DISC folder.
4. Confirm Report month. Filter by branch, report type or Normal/Special version.
   Check the files you want and choose Add selected reports.
5. Review the fixed attachments and save the routine. Importing does not send mail.

For the next monthly report, edit the routine, remove the previous saved copies,
choose the new completed ExcelFlow run and add its reports. Imported reports are
fixed snapshots: re-running ExcelFlow will not silently replace them.
Use a separate routine for Normal and Special files when they share a filename.
The existing email limits still apply: 10 attachments / 18 MB overall, and a
smaller Microsoft Graph encoded request limit (approximately 2 MB attachments).

Optional: Set ExcelFlow app folder to the folder containing Harrison ExcelFlow.exe
and _internal. Open ExcelFlow then launches that application. Keep the complete
ExcelFlow portable folder together. ExcelFlow 1.17's existing run_summary.json is
supported; no changes to its report calculations, raw workbooks or executable
are needed for this integration. Task Hub never runs arbitrary command strings.

Implementation boundaries:
- excelflow.rs validates completed run summaries, scoped paths and workbook files.
- ExcelFlowPicker.tsx handles selection; imported files use existing attachment storage.
- Import commands accept native-selected folder IDs and report keys, not arbitrary paths.
- Browser mode previews the selection only; real file snapshots use the desktop backend.
