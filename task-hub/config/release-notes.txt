Task Hub 0.7.3
- Mail connection errors now include a bounded, sanitized Server reply section with the server rejection reason.
- POP3 sign-in errors identify the PASS stage without assuming the password is incorrect.
- Server messages can reveal mailbox locking, disabled accounts and other access restrictions when the server provides that information.
- Known passwords, usernames, email addresses and common encoded credentials are redacted from server replies. Control characters and oversized replies are filtered.
- Retains POP3 SSL/TLS, STARTTLS and explicit None encryption options from v0.7.2. STARTTLS never falls back to unencrypted access.
- Incoming mailbox failures remain separate from outgoing SMTP failures. Sending behavior and automatic retry rules are unchanged.

Saved routines and attachments remain on this computer. IMAP/POP3 accounts appear as senders only after outgoing SMTP is configured and tested. SMTP continues to require SSL/TLS or STARTTLS.
