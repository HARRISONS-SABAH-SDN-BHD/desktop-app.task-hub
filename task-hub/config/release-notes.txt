Task Hub 0.7.4
- Removed Microsoft account and Outlook Classic integrations, their setup screens, backend modules and build settings.
- Removed obsolete Office app automation recipes. ExcelFlow report generation remains available.
- Gmail and IMAP/POP3 remain the supported connections. Existing routines with unsupported providers cannot run until changed to a supported sender.

- Preserves sanitized Server reply diagnostics, credential redaction and separate incoming/outgoing connection errors.
- Gmail sign-in, Google Calendar, mail-server transport, attachments and routine sending behavior are retained.
