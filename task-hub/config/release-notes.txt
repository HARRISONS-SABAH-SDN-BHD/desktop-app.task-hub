Microsoft 365 work email:
- Connect a Microsoft 365 mailbox using an IT-registered Microsoft Entra desktop/public client.
- Choose Gmail or Microsoft 365 for each routine; existing routines retain Gmail.
- Outlook drafts, scheduled sending, CC and report attachments through Microsoft Graph.
- Secure account storage and no automatic retry of email submission.
- Microsoft messages are limited to a 4 MB encoded request (about 2 MB attachments). Outlook calendar sync is not included.
